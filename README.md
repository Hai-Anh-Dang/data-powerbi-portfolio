# 🗺 Mt-H-Anh's Portfolio

I use SQL and Power BI to understand sales performance, customer purchasing, and product engagement. My Olist and Office Furniture projects examine delivery delays, cancelled orders, and repeat buying. My TaskFlow project investigates engagement and subscription decline in a fictional productivity product using synthetic data. Each case study explains what a manager could learn from the results and where more evidence is needed.
